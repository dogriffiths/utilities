The
Stylometer

Feed it a passage. It counts sentence rhythm, formulaic connectives, abstract-noun density and vocabulary turnover, then plots each measurement against a reference range of human writing. Everything is computed live from the text in the box — nothing is pre-baked.

Load a specimen

02

Plot against the reference range

Each measurement becomes a z-score: how many standard deviations from the reference mean. The shaded corridor is ±2σ, where roughly 95% of human samples fall. The first three stations are scored; the remaining five are measured but excluded, because they track genre far more than authorship.

03

The readout

Note what is not scored. Lexical variety is the feature everyone assumes runs low in machine text — and on the assistant specimen it runs conspicuously high, because survey prose piles up distinct abstract nouns while a personal narrative repeats the same handful of words. The direction of that signal flips with genre, so scoring it would be worse than useless.

What the instrument cannot tell you

Run the second specimen, then move the threshold slider. Nothing about the text changes; the verdict does. Every detector has this dial, most keep it hidden, and where a vendor sets it is a commercial decision about which error they would rather make — accusing the innocent, or missing the guilty.

Now run the third specimen: plain, careful academic English of the kind millions of competent non-native writers produce. It lands mid-scale. Leave the threshold at 65 and it is cleared; drag it to 45 — a defensible-sounding setting, and one that catches considerably more machine text — and a human writer is accused, with a large red stamp and a number that looks like evidence.

The two features doing the real work here, formulaic connectives and abstract-noun density, are honest signals. They are also a description of institutional register. A management consultant, a policy analyst and a compliance officer all write like this professionally, and the instrument cannot distinguish their prose from a model's, because at the level of these counts there is nothing to distinguish.

Finally, the base rate. Set the threshold to catch 90% of machine text and some share of human text comes with it. Across ten thousand essays, even a 2% false-positive rate produces two hundred wrongly accused people. The instrument measures a distribution. It cannot testify about a person.
